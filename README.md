# nbrsplayer

A free video player for Windows, built with C# and WPF and powered by libmpv.

The first official release, **1.0.0**, is being prepared. No download is currently available.

## Highlights

- Video playback powered by libmpv.
- Controls for playback, subtitles, audio tracks, playback speed, and picture presentation.
- Designed for Windows desktop use, with an interface available in Arabic and English.

## Requirements

- Windows 10 or Windows 11 (64-bit).
- Setup installer provided with an official release.
- No portable edition is planned.
